# Check-coin-d6-lidar
Simple LiDAR plotter application for coin-d6 LiDAR.

<img width="400" alt="Screenshot from 2026-08-25 00-48-28" src="https://github.com/user-attachments/assets/d2365b92-6037-463f-9867-724b73360a67" />



## Usage
```sh
python d6_viewer.py
```

#### How to start
1. Select Serial port.
2. Push `Connect` button.
3. Push `Start` button.

#### How to stop
Push `Stop` button.
